如何开始这项爱好？

只需三步，零门槛开启你的网页小游戏探索之旅

01

打开现代浏览器

无需高端显卡或昂贵外设，无论电脑还是手机，只要打开 Chrome、Edge 或 Safari，游戏的大门便已敞开。

02

寻找优质开源与独立平台

访问 itch.io (HTML5 专区)、Pico-8 社区或 GitHub 游戏库，发现世界各地独立开发者创作的精巧小品。

03

尝试体验并甚至亲自动手制作

先从简单的规则开始游玩。当产生兴趣后，按 F12 看看网页源码，甚至可以使用 HTML5 Canvas 动手写出属于自己的第一个游戏！
